# Client Services

## Log a query
1. **New query** (or press `N`). Start typing the complainant's name: past callers appear with their practice and history. Pick one to reuse their contact details.
2. Choose the **category**; the routing preview shows which departments get it and how long each has. Set the priority, site and description, and attach any documents.
3. **Log and route**. Each department gets its own clock and an e-mail.

A yellow **Repeat** warning means the same failure has been raised before by this complainant.

## Follow it through
- The **Query board** puts breaches first (red, then amber). Each department circle is its own clock.
- When every department has responded, the ticket shows **Start review**. Accept each response, or **Return** it with a reason.
- Record the **verification call**: who you spoke to, what was said, satisfied or not. If they are not satisfied, choose which departments must redo it.
- **Close** needs every response accepted, a satisfied call, a closure reason and a root cause. You can set a date to check that the fix worked; you'll be reminded on that day.

## Hospital bleeds
1. **New bleed request**: pick the hospital, add one line per patient, and accept or change the suggested nurse.
2. The **Bleed board** shows each bleed's six stages. Red means a stage is late.
3. Close bleeds once the report is filed (**Close N ended** closes all finished ones at once).

## Handy
- `⌘K` on a Mac (`Ctrl K` on Windows), or `/`, searches everything: ticket number, patient, requisition, complainant.
- `⌘↩` (`Ctrl Enter`) sends the note or response you are typing. `Esc` closes notifications.
- Type `@` in a note to notify a colleague.
- **Insert canned response** fills standard wording.
- Save filters on a board with **Save view**.
- Supervisors merge duplicate complainants under **Client register**.
